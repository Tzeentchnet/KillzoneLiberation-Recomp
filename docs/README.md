# Project documentation

The [repository README](../README.md) is the current source for supported
platforms, prerequisites, build commands, and public project status.

## Current guides

- [CONFIGURATION.md](CONFIGURATION.md) — graphics dialog, controller
  remapper, platform defaults, and twin-stick reference.
- [TODO.md](TODO.md) — current remaining work, release gates, and optional
  enhancements.

## Technical reference and history

- [FINDINGS.md](FINDINGS.md) — evidence-backed technical findings with stable
  `F-xxx` identifiers across the Windows and Apple Silicon work.
- [twinstickresearch.md](twinstickresearch.md) — original hidden-control
  research plus the implemented opt-in twin-stick design.
- [WORK_DONE.md](WORK_DONE.md) — chronological development archive. Branch
  names and platform descriptions in dated entries reflect their historical
  state.
- [PLAN.md](PLAN.md) — original Windows/D3D12 architecture and risk plan,
  retained as a historical design record rather than a current build guide.

Supporting reproducible reports live in [research/](../research/). Tool-specific

[PPSSPP verification](../tools/ppsspp/README.md).
