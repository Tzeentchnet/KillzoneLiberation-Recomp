# Project documentation

These documents preserve the implementation plan, measured findings, remaining
tasks, and development history without crowding the repository root.

- [PLAN.md](PLAN.md) — original architecture, decisions, phases, and risk model.
- [TODO.md](TODO.md) — current remaining work and release gates.
- [FINDINGS.md](FINDINGS.md) — evidence-backed technical findings with stable
  `F-xxx` identifiers.
- [WORK_DONE.md](WORK_DONE.md) — chronological development archive.
- [CONFIGURATION.md](CONFIGURATION.md) — graphics dialog, controller
  remapper, and twin-stick scheme reference.
- [twinstickresearch.md](twinstickresearch.md) — hidden D-pad movement,
  controller-profile APIs, and the twin-stick experiment design.

Supporting reproducible reports live in [research/](../research/). Tool-specific
instructions are documented beside the tools, including
[Ghidra integration](../tools/ghidra/README.md) and
[PPSSPP verification](../tools/ppsspp/README.md).
